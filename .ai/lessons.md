# Lessons learned

Long-term memory for AI agents working in this repository. **Read this file before starting any task.**

Detailed write-ups live in [`lessons/`](lessons/) as `YYYY-MM-DD-slug.md`. This file is the index plus the short rules distilled from them.

## How to add a lesson

1. Create `lessons/YYYY-MM-DD-slug.md` (date = today, slug = lowercase-kebab-case) using the template below.
2. Add one line to the **Index** below (newest first), linking to it.
3. If the lesson is a rule that should always apply, also add it to **Standing rules**.
4. Before adding, search the index — update an existing lesson instead of duplicating it.

Add a lesson after fixing a bug, after a surprising failure, after finding a better approach, or whenever something is worth remembering long-term.

## Lesson template

```markdown
# <Title>

- Date: YYYY-MM-DD
- Type: bug | finding | improvement | decision
- Related: <spec / run log / file paths>

## Context
What was being done.

## Finding
What was learned (root cause, surprise, better approach).

## Rule / How to apply
Concrete guidance for future work.
```
